# Data-first research pass — 26 November 2026
## Scope locked
The user wants gameplay reference, not 91 story mission walkthroughs. Exclude story mission catalogues, plot summaries and walkthroughs. Retain only named chapter/mission unlock prerequisites needed for a vehicle, item, robbery, shop or activity. Freeze UI and Android packaging until research is ready. Existing app builds are retained as historical prototypes. Automatic Android workflow is now manual-only. No warehouse exploit.
## Actual files committed
- data/vehicle-catalogue.json: 381 named source records from crlsmartnruiz/gta6-data, MIT licence (included in LICENSE-gta6-data.txt), upstream gta6intel.com. 224 explicit seat counts and 179 drivetrain facts. Source snapshot 26 Nov; older trailer-derived data mixed in, so not proof of current game values. No prices or stat values in that source.
- data/vehicles-master.json: 757 exact-name candidate records across the above, map names, selected detailed profiles and Randy references. NOT 757 distinct vehicles; aliases, variants, map labels and unverified/pre-release identifications remain. 388 class fields, 233 seat fields or disputed seat descriptions, 17 cargo fields, 14 performance profiles, two registration values, 244 labels with photo references and 422 labels with location leads. 22 detailed specification profiles retained; they are partial, not fully verified.
- data/safes-map.json: 121 mapped safe records; codes extracted only when explicitly stated, with contradictory reports retained, leading zeros preserved and no guarantee of fixed combinations.
- data/weapon-pickups.json: 128 source-mapped pickups; not 128 unique weapons.
- data/crime-pins.json: 326 map markers (44 gang, 24 bank, 87 store, 33 fence, seven payday, 35 smash, 96 towable ATM).
- data/collectibles-pins.json: 1,384 source pins across 12 categories.
- data/activities-pins.json: 1,067 source pins across 12 categories.
These subsets derive from the existing map import, not additional unique world markers. Source Open GTA 6 Map, CC BY 4.0, https://github.com/fbritoferreira/gta6 , https://creativecommons.org/licenses/by/4.0/ ; original coordinates and source IDs retained, no bundled game images. Source marker counts are not completion totals.

## Better full-data source identified
GTA Town creator page: https://gtatown.com/creators/data . As of Nov26 lists 560 vehicle rows, 202 weapons, 61 cheats, 80 challenges, 2,710 collectibles/pickups and 2,550 places. Explicit CC BY 4.0 creator export, separate licensed-vehicle API terms https://gtatown.com/licence/data apply to that separate feed and may limit other reuse. Confirm actual export terms and fields before importing. Raw creator vehicle JSON https://gtatown.com/creators/data/vehicles.json could not be retrieved: container DNS blocked, web fetch unavailable. No claim of importing those rows. If supplied as a file, inspect source schema, licences, build date, spoilers, missing fields and merge with provenance, not blind overwrites. Exclude mission export. Other source references: https://www.gtabase.com/gta-6/vehicles/ (599 site entries, not game total); https://gtarookie.com/gta-6/vehicles/ (187 logged, 152 with scanned stats); https://gtadb.io/gta-6/vehicles (503 entries); https://gta6db.io/whats-new (public recordings of game menu). Reference-only until permitted export accessible.
