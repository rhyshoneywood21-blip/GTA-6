## Release gate — still open

The tests ran through an explicitly offline harness: actual standalone HTML loaded with Playwright `setContent`, external requests blocked, storage mocked per page. The app logic and UI were exercised, but true browser-origin persistence, external iframe tiles and provider popups were not verified. The regular GitHub QA workflow must run without this harness, and its live-map suite must pass before Pages deployment. Confirm actual Pages preview on the phone, then build the Android APK; verify launcher icon/splash and upgrade compatibility on the phone. No console gameplay reproduction. Seven provider-empty directions, three unknown Bret groups, uncertain deck order and uncertain discovery triggers remain clearly qualified; 88 flamingo candidate marker records are not 88 confirmed distinct collectibles. Do not promote unverified locations or reports into guarantees.
