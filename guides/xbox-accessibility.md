# Xbox Series S — easier controls
Official settings reference (Nov 23): https://support.rockstargames.com/articles/5g5CmDTne3WcpK7nsWsMR8/grand-theft-auto-vi-accessibility-features
## Recommended setup for a player who struggles
Pause > Settings > Gameplay:
- Accessible Combat: reduces combat difficulty by adjusting enemy health and damage.
- Reduced Vehicle Damage: changes vehicle health.
- Simplified Minigames: eases multi-button tasks including hotwiring and workouts.
- Lock-on, Aim Assist, Shooting Assist and Drive-By Assist: enable/tune to comfort.
- Auto Drive: Unrestricted if desired.
- Hold Assist: shorten sustained inputs. Tap Assist: replace repeated tapping with a hold where supported. Set aim/nitrous to tap if holding is tiring.
Settings > Controller: select Default, Classic or Left-Handed, adjust aim sensitivity and deadzones. Settings > UI/Display: increase readable text, subtitles, high contrast and reduce visual effects as needed. No source reviewed establishes an earnings penalty or guarantee.
## Default layout essentials
| Input | Action |
|---|---|
| Menu / View | Pause / map |
| LT / RT | Aim or interact / fire |
| RB | Cover |
| Y | Interact |
| X / B / A | Melee / crouch / jump |
| LB tap/hold | Holster / loadout |
| Left stick click | Sprint |
| D-pad Up tap/hold | Phone / WAiNK |
| D-pad Down hold | Quick navigation |
| D-pad Right hold | Partner menu |
| Both stick clicks | Focus (remappable) |
Controls are context dependent; check displayed prompt in vehicle, menus and missions.
## Auto drive
Place waypoint; while driving hold D-pad Down, press Menu to cinematic view, hold displayed Enable Auto Drive button. Triggers change speed. Obeys traffic; not instant travel. RydeMe skip is a separate feature.
## Partner help
Call backup through phone/menu. Give long gun via hold D-pad Right + B; receive via displayed menu. Give loot bags to partner when inventory fills. Fence Goods/Sell Loot may appear with a bag; reported D-pad Right + Y in applicable context. Wait for confirmation, do not assume immediate sale or best price. Can switch driver/gunner when available. For Randy use Wait In and Follow Me.
