# Randy — expanded 22-model reference
November 26. **Not all 22 are necessarily required on your save.** Initial tracker reportedly begins 1/16; later objectives and three crossed-out board models explain conflicting totals. Check Map > Robberies > Randy's Wish List. Use actual screenshot links, not the old stylized poster map.

Only hunt these last three if your game explicitly requires them. Do not count a model as required based on a generic online list.
## RydeMe timing correction
Two Nov 25 guides specify ordering RydeMe **before** seating the partner in the target car. This is a sensible first attempt if waiting for a pickup risks tracker activation: choose Randy, secure the target, Wait In, board taxi, Follow Me, LT + displayed Skip Journey prompt ($100), wait for partner, complete delivery. No guaranteed bypass if vehicle cannot start or leave driveway. Current wanted level compatibility unknown. No local test.
