# Quick hidden gameplay mechanics
November 26, 2026. Default Xbox controls; actual context prompts override.
| Feature | How to use / why useful |
|---|---|
| Focus | Click LS + RS; inspect highlighted clues, alarms and nearby sounds |
| Enterable interiors | Dark-blue building markings are reported to indicate accessible interiors; check actual doors |
| Cash before bank unlock | Jason's bedroom floorboards are a reported early hiding place; use in-game prompt |
| Bank access | Buck Me unlocks normal banking; checking is for usable cash, do not confuse with Family Savings |
| Dolores | Feeding the snake reportedly gives a Focus benefit; check stat change |
| Vehicle controls | Hold D-pad Left to see available vehicle commands |
| NPC interactions from vehicles | Hold D-pad Up where available to see interaction options |
| Partner | Hold D-pad Right; choose context action rather than memorizing a universal combo |
| Easy play | Accessible combat, reduced damage, simplified minigames, assist settings; no verified earnings penalty found |
| Auto drive | Waypoint and driving menu; separate from instant travel |
See quick-tricks.md and xbox-accessibility.md for existing control table. Do not treat temporary Focus boosts as permanent stat gains. Contextual controls can differ by layout.
