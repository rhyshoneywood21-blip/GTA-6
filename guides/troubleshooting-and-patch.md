## What the update addresses
Reported fixes: crashes, autosaves, weather, stuck wanted levels, missing story calls, deadlift bar and partner loot-bag handoffs. Absence of an exploit in patch notes is not confirmation.
## In-game troubleshooting
- Missing RydeMe pickup: use a reachable road, confirm destination, check available phone options. If still broken, preserve a manual save and fully quit/relaunch.
- Missing Randy target: verify tracker list, request next hint, check required chapter. Some cars only appear after mission progression.
- Missing story call: ensure correct character, progress prerequisite tasks; allow in-game time. Keep earlier manual save. Patch addresses some calls, not every possible softlock.
- Missing payout: check checking account, fence status and mission completion. Do not overwrite the only pre-delivery save.
- Poor performance: use default supported settings. Unofficial Quick Resume FPS bypass can speed up simulation and is not a genuine stable performance mode.
- Cheats: can disable saving and Xbox achievements; use only separate sessions for experimentation.
